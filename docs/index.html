프로젝트 개요 및 기획

프로젝트 개요

알림 → 속도 지연 → 완전 차단

  • 사용자가 사이트별로 점진적 지연 또는 상시 차단을 선택
  • 우회 방지를 위한 7일 삭제 쿨타임
  • 지연 모드 사이트는 전체 리소스 네트워크 감속

  4. 3

핵심 시스템 로직

리셋, 감쇄, 쿨타임

  • 자정 리셋 당일 사용 시간 0분으로 초기화, 연속 초과 일수는 성공/실패에 따라 ±1일 이월
  • 성공 시 감쇄 10분 미만 사용하면 다음 날 연속 초과 -1일 (지연율 10% 완화), 0이 되면 지연 해제
  • 삭제 쿨타임 삭제 신청 후 7일(168시간) 동안 기존 정책 유지, 이후 최종 삭제
